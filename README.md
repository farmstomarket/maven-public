# Farms2Market — Public Maven Repository

Anonymous (no-token) Maven repository serving Farms2Market shared libraries.

Add to your build:
```xml
<repositories>
  <repository>
    <id>farmstomarket-public</id>
    <url>https://raw.githubusercontent.com/farmstomarket/maven-public/main/</url>
    <snapshots><enabled>false</enabled></snapshots>
  </repository>
</repositories>
```

Hosted artifacts:
- `com.i4u.synthi-ai.farmstomarket:authz-spring-boot-starter:1.0.1`
